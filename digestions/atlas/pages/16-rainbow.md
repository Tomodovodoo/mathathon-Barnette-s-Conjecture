# 16. A white tree with one token per face

The green tree crosses precisely the deleted matching spokes. Each deleted spoke belongs to one bounded black face, so that face acts as the edge's token. A tree matching gives a white spanning tree that uses every token once, and every nonroot supplies one deleted spoke. The rainbow language separates spanning-tree connectivity from the matching constraints. An ordinary tree exchange removes one edge and inserts another across its fundamental cut. The right panel records a checked such exchange on this white graph. Treehood and the one-spoke-per-nonroot condition survive, but face-token multiplicities fail, which is why arbitrary basis exchange is insufficient.
