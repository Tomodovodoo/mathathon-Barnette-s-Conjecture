Counterexample graphs for [../OPEN-PROBLEMS.md](../OPEN-PROBLEMS.md), one JSON object per file.
`V` vertices 0..V-1 of the dual triangulation, `edges` its 3V-6 edges, `root` the white root face, `about` what the graph shows.
Where present: `white_faces` lists the other white faces, a state or `unused` gives one corner per white face in that order, `rotation` gives each vertex's neighbours in cyclic order.
