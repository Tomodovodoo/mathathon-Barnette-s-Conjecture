# Exact data

All files are generated by the sequential commands in `../code/README.md`. The mathematical definitions, root choices, normalization and proof status are in `../FAMILIES.md`. Results are COMPUTED, T4, under review unless accompanied by a separate written proof. No file is an independent referee certificate.

Direct count files retain complete dual edge lists, roots, exact signed polynomial coefficients, all primal-edge avoidance counts when enumerated, and recovery-image counts. Transfer certificates retain sparse matrices and vectors. `cross-checks.json` records agreement between formulations by this author. `root-sweeps.json` demonstrates root dependence at width 6. `subdivided-stacks.json` retains the failed growing-c_min prediction.
