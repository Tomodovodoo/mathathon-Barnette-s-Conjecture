`count.py` enumerates states by a residual minimum-choice search, checks S=|det K|, derives all partners by orienting Q, and independently enumerates primal perfect matchings to count Hamiltonian complements. It explicitly recovers every tree matching at each of the three root prescriptions. Its deadline is 540 seconds; it writes each completed row before proceeding. Do not increase the inflation parameter without a new resource estimate.

`transfer.py` has two separate frontier algorithms for incidence matchings and Hamiltonian cycles. Its run stops between instances at 500 seconds, while the displayed widths and lengths complete in seconds. No claim of a hard timeout inside a much wider single instance is made. `hamilton_matrix.py` is a third counting formulation, by two induced trees. These different implementations agree in the ranges recorded by `cross-checks.json`, but all are by the same author. Independent referee review is pending.

`certify.py` and `pair_matrix.py` use a prefix through ring 2. Their JSON sequences therefore start at L=2. `hamilton_matrix.py` starts at L=0. Every sparse matrix uses row-vector convention, with entries [source,target,weight]. Pair weights are dictionaries exponent:coefficient in a cycle marker q. The normalized signed height polynomial instead uses z, and appears only in the direct-enumeration files. Confusing the two polynomials changes the quantity being counted.

Each certificate stores the complete integer matrix, initial and terminal vectors, and a scalar recurrence. For matching and HC matrices the recurrence is checked either as a Krylov vector identity or by at least D consecutive scalar discrepancies for a D-dimensional matrix. The pair certificate additionally stores a repeated Boolean state at cycle costs 0 and 1, proving eventual constant c_min=1 in that transfer. No floating point enters these certificates. Only the numerical dominant-root estimates in `recurrences.json` use approximations, after exact polynomial isolation.

`avoid.py` counts avoidance of an arbitrary input dual edge by forcing its endpoints to have the same tree color. The saved table samples the three specified root edges and an edge at the far cap. The direct enumeration JSON contains avoidance counts at every primal edge for its finite cases.
