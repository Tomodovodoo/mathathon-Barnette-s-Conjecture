The private local dashboard is `dashboard/index.html`. Build and validate from repository root:

```powershell
python -B research/2026-11-14_sol_counting-families/code/map.py
python -X utf8 -B research/2026-11-14_sol_counting-families/labyrinth/lab.py check
python -X utf8 -B research/2026-11-14_sol_counting-families/labyrinth/lab.py build
```

The frontier tracks four selected counting tasks at each tube length, not all feasible invariant values among Barnette graphs. Its 100% coverage means these four transfer quantities were computed; it does not mean the research problem or fifth-family request is solved.
