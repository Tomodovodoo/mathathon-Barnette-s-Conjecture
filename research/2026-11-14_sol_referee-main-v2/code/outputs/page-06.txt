For Ys to be a tree we need the following condition on s. The condition is sufficient for what follows and
it is not necessary: the state that Lemma 3.1 reads off an acyclic selection need not satisfy it (Section 7).
Definition 3.4. A state s is good if Qs is a forest in which each component contains exactly one root.
The unsigned manuscript [4] calls a good state a tree matching.
Lemma 3.5. A state s is good if and only if Ss is a spanning tree of T.
Proof. Ss has |V (T)| −1 edges, so it is a spanning tree exactly when it is acyclic. That happens exactly
when Qs is acyclic and adding ao and bo closes no cycle, that is, when a, b and o lie in three different
components of Qs. A forest with n edges on n + 3 vertices has three components, so this means one root
in each.

Lemma 3.6. Let s be a good state. Then Ys is a tree on the 2k faces of T, in which every face of A has
degree two and t0 has degree one. Root Ys at t0, and let Ps consist of the side that each black face shares
with its child. Then Ps is a selection, e0 ∈Ps, and for every t ∈A the side of t in Ps contains s(t).
