# Data provenance

Every file is generated by the correspondingly named command in ../code/README.md.

| File | Producer | Meaning |
| --- | --- | --- |
| exact.json | explore.py | Fifteen named instances, integer tree counts, pair-sign histograms, exact factors, floating root approximations, unrestricted triangle descent reachability |
| scan.json | campaign.py scan | Fifty-five outer-0 plantri instances through V=14; half-pair subset inequalities; all 128 cube spoke trees and an M-exchange witness |
| roots.json | secondary.py | Exact univariate and linear-substitution factors, first counterexamples in the scanned order |
| lp.json | secondary.py | Floating nonnegative mixtures of white trees for the cube and prism half-pair point |
| half16.json | half16.py | All V=16 plantri objects at outer faces 0 and 1, 370 rooted cases |
| random.json | campaign.py random | Seed 11714, fourteen instances with saved graph edges and roots; approximate uniform-state sampling; local white-face downhill trials |
| mixing.json | mixing.py | Exact enumeration of finite flip states, floating spectra and hitting-time solutions on width-4 tubes L=1,...,6 |
| packing.json | packing.py | Seed 48014, twenty-seven positive two-tree partitions with edge IDs and colours, through dual V=120 |

COMPUTED, T4. All counts are author calculations pending independent referee review. Numerical roots are not used as certificates where exact factors are available. A field called cmin_upper_bound is deliberately not an exact c_min. Cases without pairs make half-pair tests vacuous. The reconstructed 13-vertex candidate is not a verified copy of the missing paper/figures/example.json.
