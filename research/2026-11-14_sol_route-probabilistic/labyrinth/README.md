# Local research map

This dashboard is confined to the assigned folder. It contains unreviewed T2 proofs, T4 computations, conjectures and closed routes. It is not the canonical project route map. No classification frontier was claimed.

Build with Python UTF-8 mode on Windows:

```powershell
python -X utf8 research/2026-11-14_sol_route-probabilistic/labyrinth/lab.py check
python -X utf8 research/2026-11-14_sol_route-probabilistic/labyrinth/lab.py build
```

The generated local dashboard is dashboard/index.html. All source nodes are in knowledge.json, and events.jsonl marks entries backfilled from saved outputs.
