# Figure style

## Physical size and typography

The master is a 10pt `amsart` document on A4 with 1in margins. Its text block is 15.92cm wide. Never shrink a finished PDF to make it fit. Include the `-body.tex` at natural size, or include the standalone PDF at natural size after accounting for its 6pt border.

Every graph uses one TikZ unit, 0.72cm. The running triangulation's root triangle is 12 units wide, so its geometric width is 8.64cm, or 0.543 textwidth. The reserved graph envelope is 15 units, 10.8cm, or 0.678 textwidth. Exterior incidence routes may extend to 14 units; their reserved envelope is 16 units, about 0.724 textwidth including padding. The overview uses a 10cm text box, 0.628 textwidth, with its own diagram coordinates.

All graph coordinates remain identical across the sequence. Panel geometry is never rescaled. Two views stack vertically in one column, separated by 4mm, rather than becoming cramped half-width figures. Panel labels are centred below each view. A figure occupies one gallery page so its caption can remain with it. The manuscript may place single panels within the text at these same widths.

Use Computer Modern through LaTeX. Diagram labels use `\footnotesize`, 8pt in this document; captions use the class default. Do not put long definitions inside a graph. Small local labels and counts belong in the picture, interpretation in the caption. All mathematical lettering uses math mode. Do not rasterize labels or convert them to paths.

## Encodings

The authoritative implementation is `paper/figures/barnette-figs.sty`.

| Object | Fixed encoding |
|---|---|
| Context edge of T or G | 0.35pt, black at 45% |
| Black face | 9% black interior; outer face explicitly called black |
| White face | White interior, never given a competing background tint |
| Ordinary vertex | Black dot, radius 1.1pt |
| Root of T | Hollow circle, radius 2.4pt, 0.7pt outline |
| State s | Blue disk inside the black triangle near its chosen corner |
| First state r | Vermilion square, same corner-offset rule |
| D | Blue solid, 1pt, directed with 3pt Stealth arrowheads |
| Q_s | Vermilion, 1pt, 3pt dash / 1.5pt gap; orientation from r to the third corner |
| Spoke | Grey 0.4pt; retained incidence-tree spokes bold black, deleted spokes dashed |
| Spoke detour | Same blue directed stroke as D |
| White-face tree | Green 1pt dash-dot; white centres hollow green circles; root doubly outlined and labelled y_0 |
| Selected edges P | Black 1.3pt solid |
| Hamiltonian cycle or Jordan curve | Blue 1.3pt solid |
| Two induced-tree classes | Blue disks versus vermilion squares, with the same black P edges |
| Disk under discussion | Pale vermilion tint with B/W labels; counts written below the graph |

Colours are from the colour-blind-safe Okabe-Ito palette: blue `#0072B2`, vermilion `#D55E00`, green `#009E73`. Colour is never the sole discriminator between simultaneous objects. State disks differ from squares, Q is dashed, the white tree is dash-dot, and selected edges are heavier than context. In the Jordan panel the blue curve crosses edges transversely while black P edges connect original vertices. Greyscale review is part of the build inspection.

A marked corner is placed at 0.76 vertex + 0.24 face centre. It belongs to that face, not to the vertex dot. This avoids implying that one mark serves multiple incident faces. Do not add a mark manually: the assignment must pass the state checker.

## Geometry and captions

COMPUTED: `model.py` reads the fixed 24-vertex primal adjacency list and constructs its 14-vertex dual. The original Tutte layout is improved by `layout.py` with constrained optimization. Every bounded face retains its signed orientation and positive area. The saved coordinates in `layout.json` make normal builds deterministic and avoid optimization drift. `check.py` validates the selected example; this is finite evidence, not a proof of the general theorem.

Route dual edges through the midpoint of their shared primal side. Route white-tree edges through the two adjacent white centres, side midpoints and the midpoint of the deleted spoke. Never join centres by an unchecked straight chord across unrelated faces. Exterior routes are explicit polygonal arcs outside the root triangle.

Each caption starts with what to notice, identifies what changes between panels, and explains the inferential use. Specify which state stays fixed. Say when an example changes: Figure 13 uses a separate gluing witness. Do not claim that checking one example proves the arbitrary-order statement. The caption text lives in `captions.json`, generated by `draw.py`.

Reference every figure before or beside its first use. Keep the disk picture with Lemma 4.1, cancellation with fixed-s summation, and tree/cotree with the construction of P. Do not defer the local detour illustration past the nonvanishing argument, as the original does.
