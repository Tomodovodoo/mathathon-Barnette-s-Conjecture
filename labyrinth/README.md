## Commands

Run from the repository root. `-X utf8` avoids the Windows default decoding of the template.

```
python -X utf8 -B digestions/route-map/build_map.py    # figure, routes.json, ROUTE-MAP.md
python -X utf8 -B labyrinth/make_frontier.py           # frontier.json, scatter.json, cross-check
python -X utf8 -B labyrinth/seed.py                    # knowledge.json, sota.json, backfilled events
python -X utf8 -B labyrinth/lab.py check               # prints "ok"
python -X utf8 -B labyrinth/lab.py build               # dashboard and STATUS.md
python -X utf8 -B labyrinth/lab.py event computed "summary" --nodes k.D.3 --evidence path
```

## Tier policy used here

- **T1** is `LIT`. Classical results (Stein, Kelmans, Hertel, Tutte's trinity, Thomason) are published. The three 2026 papers are unrefereed preprints. The brief of this run files them as literature, so they are T1, and the status of every such node says "2026 preprint, unrefereed". Read T1 on those nodes as "stated and proved in a paper we hold", not as "peer reviewed".
- **T2** is `PROVED-HERE`. The review state is that of the agent folder: `refereed` for route-combinatorics and for the determinant claims of route-constructive and route-dimers (one independent AI referee each), `under-review` for route-graph-theory and limits, `unreviewed` otherwise (dependency-graph, machinery-literature, route-algebra, route-topology, lean-formalisation, and what the referees added themselves). No node is human-checked. A referee changed review states only. No tier was promoted.
- **T3** is used once, for the census of states, pairs and tree matchings up to 16 vertices, where two independent implementations agree on every one of the 7868 rooted triangulations (`frontier_crosscheck.json`).
- **T4** is every other computation, **T5** every conjecture, **T6** every hunch.

## The frontier

Size: `|V(T)|`, the number of vertices of the dual triangulation (the Barnette graph has `2|V(T)| - 4` vertices, and `n = |V(T)| - 3`).

Invariant: the number of tree matchings of a rooted triangulation `(T, t0)`. It is positive exactly when the state method gives a Hamiltonian cycle at that root with no cutting.

For each size the admissible values are `0` to `3^(n/2)`, the proved bound on the number of states. A value is *realized* when some rooted triangulation has that many tree matchings, *impossible* when it is odd (the signs balance) or, for sizes up to 16, when neither enumeration realises it. Sizes 6 to 16 are fully resolved. Sizes 17, 18, 23, 28 and 33 are included to show the dark part: only `0`, the rarity family `2^q` and parity are known there.

The scatter tab plots tree matchings against `cmin` for the 5088 rooted triangulations with a pair. No point lies below `2^cmin`, which is conjecture `k.D.3`.

## Known limits

- The backfilled events carry commit times of the agents' work, in UTC. Events before November 2026 have nominal dates.
- The dashboard was built and its data validated by `lab.py check`. Nobody looked at every tab in a browser during this run.
- The map was frozen at 11:15 UTC on 2026-11-14. Later reports (referee-structure, primal-proof, route-categorical, conjectures, the manuscript drafts) are not in it. Add them through `routes.py` and `seed.py`.
