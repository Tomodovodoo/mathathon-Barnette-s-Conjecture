## Rebuild

Run from the repository root with Python UTF-8 mode on Windows.

```
python -X utf8 -B digestions/route-map/build_map.py
python -X utf8 -B labyrinth/make_frontier.py
python -X utf8 -B labyrinth/seed.py
python -X utf8 -B labyrinth/lab.py check
python -X utf8 -B labyrinth/lab.py build
```

`knowledge.json` and `sota.json` are generated by `seed.py`. Events are append-only, keyed by timestamp and type when backfilling, so later builds retain old events. A historical event describes the state when recorded; later corrections do not erase it. `frontier.json`, `scatter.json` and `frontier_crosscheck.json` come from `make_frontier.py`. The engine and dashboard template remain the skill's copies.

## Tiers and reviews

T1 means published literature or a standard result. LIT records source provenance and does not promote a supplied unrefereed 2026 preprint to T1. T2 means a written proof, with its review state. An AI referee changes that state, never the tier. No node is human-checked. Newly discovered proofs inside referee reports remain unreviewed.

T3 is used for independently validated exhaustive computations, including the all-root census through 16 and the independent C1 census through 22. T4 records the newer separator-free order-24 census and other unchecked numerical campaigns. T5 is a testable conjecture and T6 a hunch. Claim-specific reviews override folder defaults. The earlier primal proof is AI-refereed; its revision and its disagreement with referee M4 are not newly refereed. Merged main theorem now has one independent AI referee, FOLLOWS; proposed ancillary edits are not certified applied. Its second cold read and the involution referee remain pending.

## Frontier scope

Size is dual order V=|V(T)|, with primal order 2V-4. The plotted invariant is the number of tree matchings at a facial root. The full admissible value spectrum is independently cross-checked only through 16. Those rows are fully resolved. Larger rows retain parity and explicit witnesses, with unknown values left unknown. Their small resolved fractions must not be read as the fraction of roots checked by newer censuses.

`frontier.json` also records `statistic_coverage` with the exact larger ranges and source paths. The all-root C1 and equality-pattern census reaches 22, on 9,531,638 facial roots, 4,656,948 feasible, independently replayed by the conjecture referee. The cycle-cover run reaches 24 only for 4-connected Eulerian triangulations, on 23,824,742 facial roots. It checks C1, equality patterns and c_min distributions, not the full invariant-value spectrum, and remains T4 under review. It observes maximum c_min=6 at order 23. The scatter is still the original 5,088 feasible-root sample through 16; its caption states that range.

The source reports include an unreviewed separator-free family with unbounded c_min. ML1 and ML2, C3 and rainbow exchange are tracked as separate questions. See the route catalogue and current open-problems chapter for exact hypotheses and counterexamples.
